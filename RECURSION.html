Recursion in C Language

Question

1.Write a C program using recursion to print numbers from 1 to 5 and then print the letter A.

CODE

#include <stdio.h>

int x = 1;

void fun()
{
    if (x <= 5)
    {
        printf("%d", x);
        x++;
        fun();
    }

    printf("A");
}

void main()
{
    fun();
}

Output

12345AAAAAA

2. Write a program of recursion and display the output.

Code 
#include <stdio.h>
int fact(int n) {
    if(n == 0 || n == 1)
        return 1;
    return n * fact(n - 1);
}
void main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);
    printf("Factorial = %d", fact(n));
}
Output 
Enter a number: 5
Factorial = 120

3. Write a program of recursion with global variable and display the output.

Code 
#include <stdio.h>
int sum = 0;   // global variable
void add(int n) {
    if(n == 0)
        return;
    sum = sum + n;
    add(n - 1);
}
void main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);
    add(n);
    printf("Sum of first %d numbers = %d", n, sum);
}
Output 
Enter a number: 5
Sum of first 5 numbers = 15

4. Write a program of recursion with local variable and display the output.

Code 
#include <stdio.h>
int sum(int n) {
    int result;   // local variable
    if(n == 0)
        return 0;
    result = n + sum(n - 1);
    return result;
}
void main() {
    int n;
    printf("Enter a number: ");
    scanf("%d", &n);
    printf("Sum of first %d numbers = %d", n, sum(n));
}
Output 
Enter a number: 5
Sum of first 5 numbers = 15
