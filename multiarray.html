MULTI DIMENSIONAL ARRAY



1. Enter the four number from user and print it into matrix

Code 
#include <stdio.h>
void main() {
    int m[2][2], r, c;
    printf("Enter 4 numbers: ");
    for(r=0;r<2;r++){
        for(c=0;c<2;c++){
            scanf("%d", &m[r][c]);
        }
    }
    printf("Matrix:\n");
    for(r=0;r<2;r++){
        for(c=0;c<2;c++){
            printf("%d\t", m[r][c]);
        }
        printf("\n");
    }
}
Output 
Enter 4 numbers: 5 5 7 8
Matrix:
5       5
7       8
